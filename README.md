# 🛒 E-Commerce Analytics: Marketing, Funnel & Product Performance

## 📌 Project Overview
Understanding the customer journey from initial click to final checkout is critical for e-commerce growth. This project analyzes Fuzzy Factory's marketing, website, and sales data to understand why website visitors drop off and which products and campaigns actually drive revenue. 

Through Exploratory Data Analysis (EDA) and SQL integrations, this project traces the customer funnel to provide practical, data-driven recommendations for improving conversions, optimizing marketing spend, and increasing customer retention.

## 🛠 Tools & Libraries Used
* **Python:** Pandas, NumPy, SciPy
* **Database:** SQLite3
* **Data Visualization:** Matplotlib, Seaborn
* **Environment:** Jupyter Notebook / Google Colab
  
## 📊 Dataset Overview
The analysis is built on a relational database structure exported to an SQLite database (E-comm.db). The core tables include:
*   website_sessions.csv (472,871 records)
*   website_pageviews.csv
*   orders.csv (32,313 records)
*   order_items.csv[cite: 1]
*   order_item_refunds.csv
*   products.csv
*Note: Missing UTM/channel fields in the sessions data were imputed with the label 'Direct

## 💡 Key Findings & Insights
### 1. Overall Conversion Rate
*   The baseline website conversion rate is **6.83%**.
*   While the marketing team successfully drives traffic to the site, the vast majority of visitors (over 93%) do not convert into paying customers, indicating a need for funnel optimization.
### 2. Campaign Performance (UTM Campaigns)
*   **Highest Conversion**: The "brand" campaign achieves the highest conversion rate at **7.79%**. However, it contributes a relatively small portion of total revenue ($194,840)
*   **Highest Revenue**: The "nonbrand" campaign serves as the primary revenue engine. Despite a lower conversion rate of **6.71%**, it generated by far the most sales, bringing in **$1.35M**.
### 3. Device Type Trends
*   **Desktop Growth**: Desktop conversion rates have shown steady, consistent growth over the analyzed period, climbing from roughly **4% to over 10%**.
*   **Mobile Stagnation**: Mobile conversions have remained stagnant, consistently tracking **below 4%**. This widening gap suggests potential UI/UX issues or friction specifically isolated to the mobile browsing and checkout experience
## 📂 Repository Contents
* `E_commerece_(EDA).ipynb`: The primary Python notebook containing the data cleaning, SQLite database creation, and exploratory visual analysis.
* `dataset/`: Folder containing the 6 raw CSV files used for this analysis (Orders, Products, Order Items, Refunds, Website Sessions, and Pageviews).
* `dataset.zip`: A compressed version of the raw datasets to accommodate GitHub's file size limits.

## 🚀 How to Run
1. Clone this repository to your local machine.
2. Ensure you have the required libraries installed (`pip install pandas numpy scipy matplotlib seaborn`).
3. Extract the `dataset.zip` folder so the CSV files are available.
4. Open `E_commerece_(EDA).ipynb` in Jupyter Notebook or Google Colab and run all cells to recreate the database and visual analytics.
